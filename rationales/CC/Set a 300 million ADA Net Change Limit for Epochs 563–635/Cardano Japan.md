# Cardano Japan

**Proposal:** Set a 300 million ADA Net Change Limit for Epochs 563–635
**Vote:** Yes
**Voter ID:** `4012cab50266efd8c5bf8f65c0f7667352631ec086e79bf5f82f0755`

[Constitutional] This governance action was reviewed in accordance with the Cardano Blockchain Constitution, focusing on whether it is appropriate to vote on this type of Net Change Limit (NCL) action and its constitutionality. The current situation requires that an NCL be established, as there is no existing NCL set for the relevant period. Establishing an NCL is a necessary and constitutional action under the governance framework. During review, no members identified any aspect of this proposal that would conflict with the Constitution. Several members noted that this is a required governance action to define the NCL for the specified period (until June 2026), and that such an action does not violate any constitutional provisions. One member abstained from fully endorsing or opposing the proposal but expressed the view that it is constitutional in nature. Some members further clarified that while the proposal’s specific value of 300 million ADA is a matter to be decided by DReps, this does not affect the constitutional compliance of the governance action itself. The act of setting an NCL is, by definition, constitutional and necessary for Treasury operation under the current governance model.
