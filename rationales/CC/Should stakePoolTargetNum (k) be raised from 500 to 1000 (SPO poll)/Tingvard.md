# Tingvard

**Proposal:** Should stakePoolTargetNum (k) be raised from 500 to 1000 (SPO poll)
**Vote:** Abstain
**Voter ID:** `646d1b3ac94568a422b687db6c47acdf849f1674982ae4f9a494be43`

---

This governance action is an Info Action seeking to establish whether there is sufficient SPO support to proceed with a future Parameter Change Governance Action that would increase stakePoolTargetNum (k) from 500 to 1000. The action does not itself change the parameter or enact any protocol change.

The proposal explicitly describes the purpose of the Info Action as obtaining a standalone, stake-weighted measure of current SPO support for a potential future parameter change. It also states that the proposed >50% SPO support standard is an interpretation for the poll result rather than an on-chain ratification threshold for the Info Action itself.

Tingvard does not consider an Info Action to be an appropriate subject for a Constitutional Committee determination. Its purpose is to gather information and signal stakeholder sentiment rather than enact a change to the Cardano ledger. The substantive constitutionality of any subsequent Parameter Change Governance Action would be assessed separately if and when that action is submitted.

The proposal itself acknowledges this distinction, stating that the Info Action is intended to obtain a clear SPO mandate for a later Parameter Change Governance Action and that the actual increase to stakePoolTargetNum would require a separate governance action.

Tingvard therefore abstains without expressing support for or opposition to increasing stakePoolTargetNum from 500 to 1000. The detailed economic, decentralization, reward and security considerations presented in the proposal are matters for SPOs and other governance participants to consider when deciding how to vote on the poll.
