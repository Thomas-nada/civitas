STORM Partners votes YES on Pebble & Ecosystem Maintenance.
This proposal is focused, practical, and directly relevant to Cardano’s developer adoption problem. Pebble offers a more familiar smart contract development path for TypeScript and JavaScript developers, while the maintenance work supports TypeScript tooling already used across the ecosystem. The proposal separates Pebble and tooling maintenance from the Gerolamo node, with a total ask of ₳4.6M.
We support this because Cardano needs more accessible builder pathways, not only stronger core infrastructure. The ask is proportionate, the scope is clear, and the work can reduce friction for developers who would otherwise avoid Cardano’s learning curve.
We vote YES and expect clear reporting on real developer usage, not only technical completion.
