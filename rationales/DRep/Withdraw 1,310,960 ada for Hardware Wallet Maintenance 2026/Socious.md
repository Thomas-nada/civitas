Socious votes Yes. This 1,310,960 ADA withdrawal funds hardware wallet maintenance for 2026 — keeping Cardano's hardware-wallet integrations current as the protocol evolves, so that signing support for new transaction features (including governance actions themselves) keeps working across device firmware and API changes. Hardware wallets are how the most security-conscious holders — often the largest ones — custody ADA and vote; if this integration layer lags a hard fork, those users are locked out of new protocol features or pushed onto hot wallets, which is a security regression for exactly the wrong cohort. This is unglamorous, security-critical maintenance, vetted and approved through the Intersect community budget process and disbursed under its milestone-based administration. Consistent with Socious's policy of supporting budget-process withdrawals, we vote Yes.
