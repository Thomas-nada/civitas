# Viet_Cardano_Community

**Proposal:** Name the Protocol Version 12 hard fork “von Bergen“
**Vote:** Yes

This proposal is an Info Action. It does not alter the core source code or pose any financial risk to Cardano.

Its sole purpose is to name the upcoming V12 protocol hard fork "von Bergen" in honor of Fabian von Bergen (also known as Zyroxa) – a Cardano SPO, Ambassador, and dedicated member who tragically passed away in January 2026. While some on-chain suggestions included alternative names (e.g., Alexander Esgen), the discussion and voting trends on-chain indicate a high degree of consensus in recognizing Zyroxa's contributions.

Our "Yes" vote on this proposal is not only absolutely secure from a system standpoint but also reflects a deep culture of gratitude, honoring the legacy and strong bonds of the Cardano community.
