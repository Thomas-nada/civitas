I’m voting YES to fund Gerolamo, a Cardano light node written in TypeScript that can run directly in the browser.

Why this matters:
🧠 Accessibility for Devs – Lower the barrier for new developers to understand and contribute to Cardano by replacing obscure Haskell-only tooling with readable, familiar TypeScript.

🌐 True Decentralization – dApps today rely on centralized full nodes. Gerolamo enables trustless, browser-based access to Cardano, removing the need for hosted infrastructure.

⚡️ Faster Adoption – Light nodes in JS unlock a whole new class of scalable, censorship-resistant apps, wallets, and dev tooling — no setup required.
