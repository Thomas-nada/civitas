While there seem to be few concerns about the proposed changes to the Plutus limits, I've seen several SPOs raise concerns about reducing minPoolCost to 75 ADA, arguing that it could make running a pool unprofitable.

I don't share this concern, because minPoolCost does not require pool operators to set their PoolCost to the minimum allowed value. The current minPoolCost is 170 ADA, yet many pools already have a higher PoolCost — 200, 340, or even 500+ ADA.

Pool operators are free to choose whatever value they consider appropriate and that allows their pool to remain profitable.

Therefore, I'm voting Yes on both parameter changes.
