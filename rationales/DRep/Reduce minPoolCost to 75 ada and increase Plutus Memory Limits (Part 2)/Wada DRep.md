# Wada DRep

**Proposal:** Reduce minPoolCost to 75 ada and increase Plutus Memory Limits (Part 2)
**Vote:** Yes
**Voter ID:** `drep1y2jnqfamg4tq5aepxhggzhqg7pq5gunph4wypkyh9q3qt2cru5m2j`

We vote yes on this governance action. We find both proposed parameter changes to be necessary and reasonably supported by evidence. Reducing minPoolCost from 170 to 75 ADA responds to the changing economics of stake-pool operation and gives smaller pools greater flexibility to remain competitive. We see this as supportive of a more diverse and resilient stake-pool ecosystem.

We also support the proposed increase in Plutus memory limits as a continuation of the previously approved, staged capacity increase. The additional execution headroom can help remove constraints on increasingly demanding smart-contract applications, while the staged approach and prior testing provide reasonable assurance that the increase can be implemented without taking disproportionate technical risks.

Although we note that the two parameter changes are technically unrelated and would ideally be considered separately, we find that both independently present a credible theory of change and a clear ecosystem need.
