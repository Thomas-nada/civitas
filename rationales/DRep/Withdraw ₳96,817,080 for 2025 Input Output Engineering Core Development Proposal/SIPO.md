SIPO casts a Yes vote on the proposal to withdraw ₳96,817,080 for the 2025 Input Output Engineering Core Development initiative.

We support this proposal for the following key reasons:
	1.	Major Scalability Upgrades (L1 and L2)
The implementation of Leios and finalization of Hydra 1.0 bring significant improvements in network throughput, user experience, and developer potential.
	2.	Enhanced Smart Contract Security & Tooling
The suite of Plutus High Assurance tools (automatic formal verification, property-based testing, static analyzer) significantly improves dApp security and developer productivity.
	3.	Modular Node Architecture (Acropolis)
A redesigned node architecture promotes openness, modularity, and easier community contribution—essential for long-term sustainability and ecosystem diversity.
	4.	Improved SPO Viability and Security
Tools like Ledger-HD, KES Agent, and LSM/UTXO-HD reduce resource consumption and improve operational security for stake pool operators.
	5.	Support for New Use Cases
Features such as Babel Fees, Nested Transactions, and Minotaur AVS open the door to new transaction patterns and revenue models on Cardano.
	6.	Transparent, Accountable Treasury Disbursement
The use of auditable smart contracts, legal delivery contracts, and oversight by Intersect and external committees ensures governance integrity and financial responsibility.

This proposal embodies a comprehensive, technically sound, and strategically aligned plan to strengthen Cardano’s core foundations in 2025 and beyond. It supports scalability, decentralization, developer adoption, and overall ecosystem maturity.

Therefore, SIPO fully supports this treasury withdrawal request.
