# drep.collective

---

We vote YES on this proposal because Mithril is an important piece of core infrastructure for Cardano. Fast, verifiable and trust-minimized access to Cardano state is essential if the ecosystem wants to scale without becoming overly dependent on centralized indexers, hosted APIs or heavy full-node requirements. Mithril can improve sync times, support light clients, strengthen cross-chain interoperability, and enable new tools for wallets, bridges, exchanges, monitoring and other infrastructure providers.

We also see this as a continuation of strategically important work that already exists and should not be interrupted. Moving Mithril from IOG-funded development toward a community-governed funding model is a sensible step for long-term sustainability. Given the clear infrastructure value, the relevance for decentralization and adoption, and the focused scope of the proposal, we support this treasury withdrawal.
