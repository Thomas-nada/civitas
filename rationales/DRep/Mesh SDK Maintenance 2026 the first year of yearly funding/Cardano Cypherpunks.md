---

Mesh is critical developer infrastructure with demonstrated and growing ecosystem usage. Its core package downloads increased from 127,746 to 311,234 year-on-year, and 889 GitHub projects depend on the SDK. The proposal also demonstrates concrete delivery: Mesh supported the PV11 hard fork, resolved compatibility issues before mainnet, introduced on-chain governance functionality, added new data providers and delivered tools for local smart-contract testing. Its x402 payment integration and support for programmable tokens are particularly relevant to expanding Cardano's commercial utility.

The ₳600,000 request is relatively modest for infrastructure with this reach, and the 2026 reference year provides measurable evidence of actual work rather than speculative future deliverables. The budget is transparent, payments require 3-of-4 multisig approval, and the team commits to public reporting and returning unspent funds. The main weakness is that downloads and GitHub dependencies do not necessarily translate into active applications, transaction volume or revenue. Nevertheless, maintaining widely adopted infrastructure is a necessary enabler of commercial adoption. I support funding, while expecting future proposals to demonstrate how Mesh usage translates into production applications and sustained on-chain activity.
