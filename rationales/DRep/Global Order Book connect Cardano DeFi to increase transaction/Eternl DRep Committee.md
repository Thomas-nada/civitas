# Eternl DRep Committee

**Proposal:** Global Order Book connect Cardano DeFi to increase transaction
**Vote:** No
**Voter ID:** `drep1y29h2q6cst2pvkl2sqqvf5ljcy36uv7pmy482xnczddzgqshus24w`

---

We voted NO, while recognizing that the proposal addresses a real challenge for Cardano DeFi and that Dano Finance is a capable team.

Our main concern is that the proposal combines public infrastructure with significant funding for Dano’s commercial products. We would prefer these elements to be assessed separately.

We also believe the proposal needs a more detailed budget, and a more meaningful long-term return for the Treasury.

We would reconsider a revised proposal addressing these points.
