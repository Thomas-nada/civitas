I voted YES for the Govtool proposal.

Here are the reasons:

There are still very big concerns about the barriers to participation in Cardano governance. In particular, the majority of Cardano wallets are reluctant (low priority) to improve governance functions. As a result, a large number of DReps are abstaining and governance participation rates are declining. This needs to be resolved.

In particular, only Eternl, Typhon, and Gero wallets meet all of the following criteria.

Display list of DRep in wallet
DRep Name Search Delegation UI
4 clicks + under 30 seconds DRep delegation

Of these, only Typhon meets DRep Neutrality.

To implement these features within the wallet, cooperation from wallet providers is essential, but it may be possible to speed up implementation using Govtool's API and services.

In addition, there are few DRep search tools in use. After all, most ADA holders delegate to DReps they have seen on social media or DReps recommended by their wallet providers. A neutral tool to improve these situations is needed.

Also, most DReps do not attach the reason for voting, which is related to UI issues. DRep is busy.

Govtool has promised to manually prioritize the implementation of these features based on DRep/community feedback. I think the cost is not cheap, but considering that Govtool currently provides the most features, there is a high risk of eliminating this.

I want to ensure that feedback on feature implementations is collected and prioritized to some extent before Treasury Withdrawals.

私はGovtool提案書にYESを投票しました。

理由は次のとおりです。

Cardanoのガバナンスの参加障壁は非常に大きな懸念が残っています。特にCardanoウォレットの大多数はガバナンス機能の充実化に消極的（優先順位が低い）です。結果として大量の棄権DRepの発生とガバナンス参加率の低下が起きています。これを解決する必要があります。

特に、次の全てを満たすウォレットはEternl、Typhon、Geroのみです。

Display list of DRep in wallet	
DRep Name Search Delegation UI
4 clicks + under 30 seconds DRep delegation

DRep Neutralityを満たすのはその中で、Typhonのみです。

これらをウォレット内部で実装するためには、ウォレットプロバイダーの協力が不可欠ですが、Govtool のAPIやサービスなどで実装を早めることが可能である可能性があります。

また、結局DRepの検索ツールで使われているものはまずありません。結局のところほとんどのADAホルダーはSNSなどで見かけたDRepまたはウォレットプロバイダーが推奨するDRepに委任しています。これらの状況を改善する中立的なツールが必要です。

また、投票理由をほとんどのDRepが添付していませんが、これはUI上の問題が関係しています。DRepは忙しいのです。

Govtoolはこれらの機能実装をDRep/コミュニティのフィードバック手動で優先順位づけすることを約束しています。コストは安くないと思いますが、しかし現状で最も多くの機能を提供しているのがGovtoolであることを考えると、これを廃止するリスクの方が高い状況にあります。

私は、トレジャリー引き出しまでに一定程度、機能実装に関するフィードバックが収集され、優先順位づけされていることを確認したいと思います。
