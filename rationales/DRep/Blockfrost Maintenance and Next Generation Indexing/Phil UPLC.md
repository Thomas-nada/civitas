Support because RPC and indexing are table-stakes infrastructure for developer onboarding and application continuity, and because the current ecosystem has too much concentrated dependency on Blockfrost as a core access provider. The important funding case is decentralization: Project Cayley, decentralized slice indexing, and a broader operator model can move Cardano away from one dominant hosted path toward resilient, lower-cost, independently operated data access. This should be treated as crucial public infrastructure if it demonstrably reduces single-provider risk rather than deepening it.
