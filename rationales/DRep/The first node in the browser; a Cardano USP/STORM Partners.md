# STORM Partners

**Proposal:** The first node in the browser; a Cardano USP

STORM Partners abstains on the Gerolamo browser node proposal.
We respect Harmonic Labs and recognize the technical ambition behind a browser-based Cardano node. If successful, it could become a distinctive Cardano capability. That said, we are not fully convinced this should be a priority under the current NCL. Cardano already has several alternative node initiatives in motion, and we do not have enough confidence that this specific node path should rank above more immediate infrastructure, scaling, and adoption needs.
Given our limited technical certainty here, we abstain rather than vote NO.
