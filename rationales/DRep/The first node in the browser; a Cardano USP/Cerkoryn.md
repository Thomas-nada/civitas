Gerolamo offers a unique value proposition over the existing Haskell node and the other alternate nodes in development (Dingo, Amaru, etc.). In my mind, the other nodes are geared toward SPOs, but Gerolamo will be a major benefit toward dApp and light wallet developers. As a native TypeScript node, Gerolamo will be catering toward one of the most highly-adopted languages on the planet. With the capability to run a node in the browser, this opens up a lot of new use cases for developers that we simply don't have with other nodes or tooling.  For these reasons I am enthusiastically voting YES on the Gerolamo proposal.
