Cardanoには、Yoroi、Lace、Eternlなど複数の重要なウォレットが存在し、それぞれ異なるユーザー層を支えています。Yoroiは長期保有者やステーキング利用者に広く使われ、Laceは標準的で使いやすいCardanoウォレット体験を担う存在として発展しています。その中でEternlは、DApp利用者、DeFi・NFT利用者、DRepやガバナンス参加者、マルチシグ利用者、ハードウェアウォレット利用者など、Cardanoをより深く実用する層にとって重要なライトウォレットです。
Eternlが縮小・停止すれば、特にパワーユーザー、DApp利用者、DRep投票者、マルチシグ利用者、ハードウェアウォレット利用者に影響が出る可能性があります。Eternlは民間プロダクトではありますが、Cardanoエコシステム上では、実利用・DApp接続・ガバナンス参加を支える準公共インフラとして扱う余地があると考えます。
また、本提案は単なる継続補助ではなく、Proプランによる自立化、公開会社ウォレットでの資金管理、余剰時のTreasury返済、条件達成後の追加寄付という、Treasuryへの還流を意識した設計を含んでいる点を評価します。Treasury資金を一方的な支出で終わらせず、将来的にエコシステムへ循環させようとする前向きな試みです。
一方で、本提案はマイルストーン型ではなく、メインUIもオープンソースではありません。また、ウォレットという重要インフラに対して監査費の比率が小さい点には注意が必要です。そのため、Pro収益、資金残高、Treasury返済状況、稼働率、セキュリティ対応、主要開発成果について、定期的かつ検証可能な報告を求めます。
これらの透明性と説明責任が実行されることを前提に、Eternlの継続はCardanoの利用体験、DApp利用、ガバナンス参加を支える重要な投資であると考え、本提案を支持します。

I support this proposal.

Cardano has several important wallets, including Yoroi, Lace, and Eternl, each serving different user groups. Yoroi has long supported holders and staking users, while Lace is developing as a more standard and user-friendly Cardano wallet experience. Within this landscape, Eternl plays an important role for power users, DApp users, DeFi and NFT users, DReps, governance participants, multisig users, and hardware wallet users.

If Eternl were to scale down or stop operating, the impact would be felt especially by these active user groups. Although Eternl is a private product, it can reasonably be regarded as semi-public infrastructure within the Cardano ecosystem because it supports practical usage, DApp access, and governance participation.

I also appreciate that this proposal is not merely a request for continued support. It includes a path toward sustainability through the Pro plan, public fund management, treasury repayment when there is surplus, and additional donations if revenue exceeds the stated threshold. This shows awareness of returning value to the Cardano Treasury rather than treating treasury funding as a one-way expense.

At the same time, this proposal is not milestone-based, the main UI is not open source, and the audit allocation appears limited for such important wallet infrastructure. Therefore, I expect regular and verifiable reporting on Pro revenue, remaining funds, treasury repayments, uptime, security handling, and major development progress.

With these expectations for transparency and accountability, I believe continued support for Eternl is an important investment in Cardano’s user experience, DApp access, and governance participation. Therefore, I support this proposal.
