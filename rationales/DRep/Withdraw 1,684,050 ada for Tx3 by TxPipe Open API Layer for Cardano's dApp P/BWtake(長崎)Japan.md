I support this Treasury Withdrawal.

Tx3 is an important DevX public infrastructure that allows Cardano dApp protocols to be discovered, integrated, and executed through a common interface by developers, wallets, aggregators, and AI agents. While Cardano’s UTxO/eUTxO-based dApps are robust, each protocol requires specific understanding of transaction patterns, which raises integration costs. Tx3 helps reduce this friction through common APIs, SDKs, and a Protocol Registry.

I also value TxPipe’s proven track record with Pallas, Dolos, UTxO RPC, and other Cardano infrastructure, as well as the existing Tx3 developer layer and multiple protocol onboardings. The additional 12 protocol onboardings, MCP server, and agent skills framework can help move Cardano toward a protocol ecosystem ready for the AI agent era.

From a funding-management perspective, I also appreciate the inclusion of Intersect-managed Smart Contract Disbursement, milestone-based controls, oversight, and dashboard transparency. This is a reasonable structure for managing Treasury funds in a verifiable way.
