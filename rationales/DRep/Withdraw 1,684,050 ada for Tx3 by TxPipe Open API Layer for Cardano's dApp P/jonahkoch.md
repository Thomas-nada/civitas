Voting yes. Tx3 and UTxO RPC are complementary layers of the same developer access problem, and TxPipe is the team I'd back to build both. UTxO RPC standardizes how developers read chain state across node implementations. Tx3 standardizes how developers interact with the protocol layer, the actual dApps and DeFi protocols built on Cardano. Without the second layer, developers who can now query chain state still have to reverse-engineer each protocol's transaction patterns individually. That fragmentation is a real adoption tax.
The live integrations matter here. Strike Finance, Indigo Protocol, VyFinance, Bodega Market, and Fluid Tokens are already accessible through Tx3's interface. This isn't a proposal for infrastructure that might exist, it's funding expansion of infrastructure that works. TxPipe has 26 delivered Catalyst proposals and a clean 2025 Intersect record. They ship.
The agent infrastructure component is the element that distinguishes this proposal from standard developer tooling. An MCP server with per-protocol tools and LLM-structured documentation means AI agents can interact with Cardano protocols through the same patterns they use everywhere else in the agentic ecosystem. Cardano's eUTxO model is deterministic — transaction outcomes can be computed before submission, which matters enormously for autonomous agents that need predictable execution without failure surprises. That's a genuine architectural advantage, but only if the protocol abstraction layer exists to surface it. Tx3 builds that layer. The Masumi use case on Hydra — agent-to-agent commerce at the payment layer, requires that the broader Cardano protocol ecosystem is equally agent-accessible. Tx3 is what makes that true above the settlement layer.
At ₳1,684,050, this is a modest investment in infrastructure that positions Cardano's protocol ecosystem for the shift toward autonomous on-chain interaction while removing immediate friction for developers today. The ask is fair for the scope, the team has proven they deliver, and the strategic positioning is real.
