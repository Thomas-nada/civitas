SIPO DRep votes YES, with expectations, on the treasury withdrawal of 1,684,050 ada for Tx3 (TxPipe) — Open API Layer for Cardano's dApp Platform.

Why SIPO votes Yes. Tx3 is an open API layer for the dApp platform. An open, maintained API surface is the difference between an ecosystem builders can enter and one gated behind bespoke integrations.

SIPO DRep votes on this action as part of the 2026 Intersect Budget Process infrastructure batch — eleven treasury withdrawals submitted in a single transaction by Intersect on behalf of vendors, each having achieved the required 67% support threshold in the 2026 Intersect Budget Process Hydra Voting phase.

Shared basis. All eleven withdrawals share a single on-chain recipient: the 2026 Intersect Treasury Reserve Smart Contract at the script credential stake1784sdxt6jjennmstphgdu7l7c2scf5d02a6cve2dgn5s2kq5u3j9v, built on the Sundae Labs treasury-contracts framework. Disbursement is milestone-gated through a Project-Specific Smart Contract; authorization requires a quorum spanning Intersect admins, Intersect leadership and independent trusted entities; an Oversight Committee of six external parties — Sundae Labs, Cardano Foundation, Dquadrant, NMKR, Sundial and Eternl — independently verifies key administrative actions using on-chain logic; the contracts cannot be staked with an SPO and are delegated to the auto-abstain DRep; and a public dashboard lets the community audit the flow. This is the strongest fund-control class SIPO recognizes, and the same structure SIPO has already supported on Cardano Critical Integrations V2, Cardano Vision 2026, IO Hydra and Tweag Core Cardano Infrastructure. SIPO voted Yes on the Cardano Budget Process Framework and holds that treasury allocation should converge and mature through that route; having supported the route, SIPO does not reject its outputs absent a specific defect. This withdrawal complies with the 350M Net Change Limit covering Epochs 613 to 713 and with guardrail TREASURY-02a.

Expectations attached to this Yes. (1) Milestone-level reporting through the TRSC and PSSC of what was disbursed, to whom, and against which deliverable, surfaced on the public dashboard. (2) Continued open-source release of the funded work, and a clear statement of which work is baseline maintenance versus new development. (3) Continued independence of the Oversight Committee, and transparent tracking of cumulative treasury receipts by the recipient and by Intersect. (4) Where scope could overlap with other funded efforts, articulation at ecosystem level of the boundary, so that scope does not silently duplicate.

This vote is SIPO DRep's recorded position.

SIPO DRep として、Tx3 (TxPipe) — Open API Layer for Cardano's dApp Platform（1,684,050 ada）のトレジャリー引き出しに、期待事項付きで賛成（YES）を投じます。

SIPO が賛成する理由。Tx3 は dApp プラットフォームのためのオープン API 層です。開かれ、保守された API 面があるかどうかは、ビルダーが参入できるエコシステムか、個別統合の背後に閉ざされたエコシステムかの分かれ目です。

SIPO DRep は、本アクションを 2026 Intersect Budget Process インフラ・バッチ（Intersect が各 vendor を代表して単一トランザクションで提出した 11 件のトレジャリー引き出し。いずれも 2026 Intersect Budget Process の Hydra Voting フェーズで必要な 67% の支持閾値を達成）の一部として評価しました。

共通の根拠。11 件すべてが単一のオンチェーン受領先を共有します: script credential stake1784sdxt6jjennmstphgdu7l7c2scf5d02a6cve2dgn5s2kq5u3j9v の 2026 Intersect Treasury Reserve Smart Contract（Sundae Labs の treasury-contracts フレームワーク）です。払い出しは Project-Specific Smart Contract を通じてマイルストーンでゲートされ、承認には Intersect の admin・leadership・独立した trusted entity にまたがる定足数を要します。6 社の外部 Oversight Committee（Sundae Labs・Cardano Foundation・Dquadrant・NMKR・Sundial・Eternl）がオンチェーンロジックで主要な管理アクションを独立検証します。コントラクトは SPO にステークできず auto-abstain DRep に委任され、公開ダッシュボードでコミュニティが資金の流れを監査できます。これは SIPO が認める最強クラスの fund-control であり、SIPO が既に支持した Cardano Critical Integrations V2・Cardano Vision 2026・IO Hydra・Tweag Core Cardano Infrastructure と同一の構造です。SIPO は Cardano Budget Process Framework に賛成しており、トレジャリー配分はこのルートで収斂・成熟すべきだと考えます。ルートを支持した以上、特段の瑕疵がない限りその産物を拒みません。本引き出しは Epoch 613〜713 を対象とする 350M Net Change Limit および guardrail TREASURY-02a に準拠しています。

本賛成に付す期待事項。(1) TRSC / PSSC を通じて、何が・誰に・どの成果物に対して払い出されたかをマイルストーン単位で報告し、公開ダッシュボードに反映すること。(2) 資金提供された成果のオープンソース公開を継続し、どこまでが baseline の保守で、どこからが新規開発かを明示すること。(3) Oversight Committee の独立性を維持し、受領者および Intersect の累計トレジャリー受領額を透明に追跡すること。(4) 他の資金提供済の取り組みとスコープが重複しうる場合、その境界をエコシステムレベルで明確化し、暗黙裡に重複しないようにすること。

本投票は SIPO DRep の記録上の立場表明です。
