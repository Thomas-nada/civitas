I support this Treasury Withdrawal.

Dolos is not a block-producing node, so it does not directly increase SPO decentralization. However, as a lightweight data node written in Rust, it strengthens Cardano’s data access infrastructure, client diversity, and tooling diversity.

Even if Cardano’s L1 consensus layer is decentralized, practical centralization can still remain if wallets, dApps, explorers, and indexers depend on only a few API providers or heavy full-node infrastructure. Dolos helps reduce this dependency by giving builders more ways to access Cardano data.

For this reason, I evaluate Dolos as public infrastructure that improves decentralization and resilience at the practical usage layer of the Cardano ecosystem.
