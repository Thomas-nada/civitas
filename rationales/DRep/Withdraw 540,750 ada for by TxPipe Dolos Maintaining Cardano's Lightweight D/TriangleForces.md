The ₳541K request to keep Dolos going makes sense considering it's a lightweight, resource-efficient data node that supports multiple API protocols. 

That said, the proposal doesn't quite show how Dolos stands out or adds more value compared to existing solutions like Blockfrost or full nodes that are enhanced by Hydra and Layer 2 scaling. For future funding to be justified, we need stronger proof of Dolos’s adoption, performance, and real impact on the ecosystem. If there's no clear differentiation or solid usage metrics, ongoing funding could just lead to more duplication instead of promoting strategic consolidation and efficiency.

The budget seems reasonable if Dolos can continue to fill a specific niche, but I would expect clearer KPIs and a comparison to the alternatives next time. Treasury funds should create real value and not support redundant infrastructure.
