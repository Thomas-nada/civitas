# Cardanians

**Proposal:** Se7en Labs Daedalus Wallet Maintenance and Improvements 2026-2027
**Vote:** No
**Voter ID:** `drep1yt4lyf0fwlrz8k6j5evd3rxw0sqp67qkh36su98a97q3qsc0h03y4`

---

We recognize Daedalus as an important open-source public-good wallet and Cardano’s full-node desktop wallet option. It supports self-sovereign access without relying on third-party APIs or hosted backends, which has value for ecosystem resilience.

However, we do not believe the case for continued treasury funding is strong enough in the current form. Daedalus serves a relatively small user base compared with light wallets, and the proposal would benefit from clearer evidence of current demand, usage trends, support load, release cadence, and long-term sustainability.

We also want clearer justification of which improvements are essential maintenance versus new feature development, and how future funding needs should be handled if Daedalus remains a niche wallet.

This is not a rejection of Daedalus. It is a decision that the public-good value is real, but not sufficiently justified against current usage and competing treasury priorities.
