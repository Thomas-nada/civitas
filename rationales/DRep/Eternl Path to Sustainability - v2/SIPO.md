SIPO DRep votes YES, with expectations, on Eternl: Path to Sustainability - v2.

This is a resubmission of "Eternl: Path to Sustainability (2026-2027)," a proposal SIPO already voted Yes on, with expectations, on 3 June 2026. That earlier version did not pass because Constitutional Committee members voted No, citing a lack of clarity on how audit funds would be spent and overseen. This v2 adds exactly that clarification — the audit spending and oversight metrics the Committee asked for — updates the ADA-to-USD conversion rate, and notes that Eternl's own DRep will abstain on the action. The substance is otherwise the same proposal SIPO has already endorsed.

Eternl is core, non-custodial wallet infrastructure and a Cardano public good. It runs across web, extension, Android, and iOS with an install base around 130,000, carries an estimated 10 to 18 percent of Cardano mainnet transactions, supports 66 languages, has operated for over five years with essentially zero downtime, and is currently the only wallet offering comprehensive in-app governance tooling that lets ada holders browse proposals and see how DReps voted. Reliable access to Cardano that is independent of any single front end or venture backer is exactly the kind of infrastructure the treasury should keep healthy.

The request is 2,350,000 ADA for twelve months. This is a larger ADA figure than the earlier proposal's 1,680,000 ADA, but the underlying budget is essentially unchanged: it is approximately 420,000 USD, and the ADA amount rose only because the conversion rate was updated to about 0.1787 USD per ADA to reflect the lower ADA price. The factor that decided SIPO's earlier Yes applies unchanged here: Eternl commits to a path off treasury dependence through its Pro-plan revenue and to returning surplus to the treasury on a defined schedule, so this is framed as a bridge to self-sufficiency rather than an open-ended subsidy.

SIPO records the same fund-control limitation it disclosed the first time, plainly. The withdrawal recipient is a single key-hash credential, not the audited script escrow that represents SIPO's strongest treasury-protection standard. Repayment and oversight are therefore not enforced on-chain; they rest on the proposal's written commitments, on Eternl's public reporting, and on the reputation of a product that has run reliably for years. SIPO distinguishes this from proposals it has abstained on or opposed: unlike those, Eternl does not claim an escrow it does not have — it is transparent that this is an operating wallet funded to a key-hash with a repayment obligation — and it pairs that obligation with a self-sufficiency plan. On that basis a key-hash recipient is acceptable here where it was not elsewhere. There is no conflict of interest for SIPO, since general use of a wallet is not a basis for recusal, and Eternl's own DRep abstaining on its action is sound governance hygiene.

SIPO therefore votes Yes with the following expectations, carried forward from its first vote and extended for v2: (1) publish the real active-user rate behind the install base, not only the install count; (2) report Pro-plan conversion and concrete progress toward self-sufficiency; (3) publish the treasury-repayment transactions at each defined interval, so the repayment commitment is verifiable on-chain; (4) disclose how this funding relates to the rest of Cardano's wallet-maintenance portfolio, so overlap is avoided; and (5) honour the newly added audit-spending clarity by reporting the audit expenditure and oversight metrics that this v2 was resubmitted to provide. This vote is SIPO DRep's recorded position.

SIPO DRep として、本提案「Eternl: Path to Sustainability - v2」に、期待事項付きで賛成（YES）を投じます。

本件は、SIPO が 2026年6月3日に期待事項付きで賛成（YES）を投じた提案「Eternl: Path to Sustainability (2026-2027)」の再提出版です。前回版は、監査資金の使途と監督の明確性を欠くとして Constitutional Committee メンバーが反対（No）を投じたため、不成立となりました。本 v2 は、まさにその明確化 ― 委員会が求めた監査支出と oversight metrics ― を加え、ADA/USD 換算レートを更新し、Eternl 自身の DRep は本アクションを abstain する旨を明記しています。それ以外の本体は、SIPO が既に支持した提案と同一です。

Eternl は、中核となる非カストディ型 wallet インフラであり、Cardano の公共財です。web・拡張機能・Android・iOS で稼働し、install base は約 13 万、Cardano mainnet トランザクションの推定 10〜18% を担い、66 言語に対応、5 年以上ほぼ zero downtime で運用され、現在、ada ホルダーが提案を閲覧し DRep の投票状況を確認できる包括的な in-app ガバナンスツールを提供する唯一の wallet です。特定のフロントエンドや VC に依存しない、信頼できる Cardano へのアクセスは、まさにトレジャリーが健全に保つべきインフラです。

要求額は 12 ヶ月で 2,350,000 ADA です。これは前回提案の 1,680,000 ADA より大きい ADA 額ですが、基礎となる予算は実質的に変わっていません。約 420,000 USD であり、ADA 額が増えたのは、ADA 価格の下落を反映して換算レートが約 0.1787 USD/ADA に更新されたためにすぎません。SIPO の前回の賛成を決めた要因は、ここでもそのまま当てはまります。Eternl は Pro plan 収益によるトレジャリー依存からの脱却と、定められたスケジュールでの余剰返還にコミットしており、本件は青天井の補助金ではなく自立への橋渡しとして枠組みされています。

SIPO は、前回率直に開示したのと同じ fund-control の限界を、ここでも率直に記します。引き出し先は、SIPO の最強のトレジャリー保護基準である監査済み script escrow ではなく、単一の keyHash クレデンシャルです。したがって返済と監督はオンチェーンで強制されず、提案の書面上のコミットメント、Eternl の公開報告、そして長年信頼性高く稼働してきた product の評判に依拠します。SIPO はこれを、abstain・反対した案件とは区別します。それらと異なり、Eternl は持たない escrow を主張しておらず ― これは keyHash に返済義務付きで資金供給される稼働中の wallet だと透明に示しており ― その義務を自立計画と組み合わせています。この点で、他では受け入れなかった keyHash 受領を、本件では受け入れられます。SIPO 側に COI はなく（wallet の一般利用は recusal の根拠になりません）、Eternl 自身の DRep が自案件を abstain することは健全なガバナンス上の作法です。

したがって SIPO は、前回の投票から引き継ぎ v2 向けに拡張した以下の期待事項とともに賛成します。(1) install 数だけでなく、その背後にある実アクティブユーザー率を公開すること、(2) Pro plan の転換率と自立への具体的な進捗を報告すること、(3) 返済コミットメントがオンチェーンで検証可能となるよう、定められた各期のトレジャリー返済トランザクションを公開すること、(4) 重複を避けるため、本資金が Cardano の他の wallet 保守 portfolio とどう関係するかを開示すること、(5) 本 v2 が提供するために再提出された監査支出の明確化を履行し、監査支出と oversight metrics を報告すること。本投票は SIPO DRep の記録上の立場表明です。
