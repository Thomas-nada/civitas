---

After reviewing the proposed changes to the Cardano Constitution, I have decided to lean toward a YES vote on this proposal.  I think that the changes are an improvement over the existing Constitution, but there is still a lot more to be desired.

The Good:
-Removal of the Budget Info Action and establishing the auditing/administrator/oversight requirements in the Treasury Withdrawal instead.
-Removing requirement for dRep Codes of Conduct (as these were generally unenforceable anyways).
-Adding a requirement for immutable URLs to governance actions.

The Bad:
-Clarity on the NCL is still somewhat lacking.
-Staggering CC members. I'm not sure how this would work given that the ledger only recognizes a single CC at a time.  Additionally, I don't think it is enforceable.
-Treasury withdrawals requiring the identity of the recipient. To me this seems like it would implement a hard KYC requirement and not allow pseudonymous community figures (i.e., Hosky, Cardano Whale, etc.) from ever proposing a treasury withdrawal.
-"DReps have voting power equal to the number of Lovelace delegated to them." This would prevent changes such as quadratic voting power, which I think is something that should be left open for exploration.
-Required disclosures for people who hold multiple roles (dRep, SPO, CC). Also required disclosures for compensation.  I don't think these are enforceable. And if they were, it could be the case that a single dRep refusing to disclose something might make the entire governance action unconstitutional.
