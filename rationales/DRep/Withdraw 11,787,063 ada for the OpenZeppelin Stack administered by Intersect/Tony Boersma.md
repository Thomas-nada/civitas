# Tony Boersma

I support the goal of bringing high-quality, audited development infrastructure to Cardano, but I believe the proposal is too broad and too expensive as currently structured. In particular, the three Reference Implementations should be removed from this engagement and evaluated separately, allowing the core contracts library and security work to be assessed on their own merits. The recent increase in ADA’s value also materially changes the economics of a fixed-ADA request, making the proposal substantially more funded in dollar terms than when the budget was established. Given the Treasury’s finite resources, I believe we should take advantage of that increased purchasing power rather than allowing the full original ADA allocation to remain unchanged. A narrower proposal focused on the core OpenZeppelin infrastructure would be easier to justify and provide better value for the Treasury.
