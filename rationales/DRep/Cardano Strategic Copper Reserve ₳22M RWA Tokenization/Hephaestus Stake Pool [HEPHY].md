I vote NO on the Treasury Withdrawal action "Cardano Strategic Copper Reserve | ₳22M RWA Tokenization" (6eddf4f1dbad06f329aa69743559c4930b7b689f16c073061d228d9c6613d19c#0).

This proposal was unconstitutional from the moment it was submitted, on two grounds; the proposal metadata itself uses [non-immutable storage](https://totofinance.com/cardano-treasury-proposal-strategic-tokenized-copper-reserve/data.jsonld), and the [receiving address](https://cardanoscan.io/stakeKey/stake1uxmfznssgltfuakxlluxdecmu9wwd48kw0pz0qhugaxyjyguc0tax?tab=delegationHistory) has been delegated to a stake pool since October 15, 2026. This remains the case on the last day of the `govActionLifetime`, despite having been highlighted as an issue by a number of other voters.

These are very basic due diligence checks prior to action submission, and if the simplest due diligence can't be completed, then it is unfair to expect DReps to dedicate their precious time to evaluating it any further. If hosting metadata on GitHub is the only option, use GitHub permalinks — it is as simple as pressing the "y" key while in the repository. When committing 100,000 ada and 6 epochs of voters' time, consider having someone better versed in Cardano governance actions look over the proposal first, or use a testnet before Mainnet.
