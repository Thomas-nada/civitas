# Rationales

Vote rationales from DReps, SPOs, and Constitutional Committee members on all Cardano governance actions.

Updated automatically every 12 hours via GitHub Actions.

## Structure

```
rationales/
  DRep/<Proposal Title>/<Voter Name>.md
  SPO/<Proposal Title>/<Voter Name>.md
  CC/<Proposal Title>/<Voter Name>.md
```

Each file contains the voter's rationale text as published at their rationale URL, along with their vote choice and voter ID.

Source: [Civitas](https://civitas-nglb.onrender.com)
