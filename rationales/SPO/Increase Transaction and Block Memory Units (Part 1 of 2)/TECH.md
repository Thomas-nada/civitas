I will vote YES on this proposal to increase the maxTxExecutionUnits[memory] and maxBlockExecutionUnits[memory] to 16,500,000 and 72,000,000 respectively as this parameter increase has been discussed all the way back in Dec 2023. The parameter change has been extensively benchmarked and does not seem to have an significant negative change to network troughput as well as hardware requirements to run the cardano-node. This change will make it easier to develop effcient dapps for the Cardano blockchain.
